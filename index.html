      필카운터란?

      사진 한 장으로 같은 약이 몇 알인지 자동으로 세어 주는 앱입니다. 터치한 약과 색·모양·크기가 같은 약만 셉니다.

      ① 촬영

      1. 약을 단색 배경 위에 최대한 겹치지 않게 펼칩니다.
      2. 휴대폰을 약 바로 위에서 수평으로 들고, 약이 화면에 가득 차게 맞춥니다.
      3. 📷 촬영을 누르거나 화면을 누릅니다. 이미 찍은 사진은 🖼 불러오기로 가져옵니다.

      ⚡ 실시간 계수

      1. 카메라를 켜면 처음부터 실시간으로 시작합니다. 끄고 싶으면 ⚡ 실시간 켜짐 버튼을 눌러 끕니다(설정은 기억됩니다).
      2. 카메라 화면에서 약 한 알을 터치하면, 비추는 동안 개수가 계속 바뀌며 표시됩니다.
      3. 숫자가 안정되면 📷 촬영을 누르세요. 고화질 사진으로 다시 정밀하게 세어 결과 화면으로 넘어갑니다.
      4. 실시간 숫자는 빠른 미리보기용입니다. 최종 수량은 확정 후 결과를 기준으로 하세요.

      ② 자동 계수

      1. 촬영하면 터치 없이 자동으로 셉니다. 사진에서 같은 모양·색으로 가장 많이 반복되는 물체를 약으로 판단합니다.
      2. 여러 종류의 약이 섞여 있거나 다른 약을 세고 싶으면, 결과 화면의 🎯 직접 선택을 누르고 그 약 한 알을 터치하세요.
      3. 실시간 화면에서도 자동으로 세며, 원하는 약을 터치하면 그 약으로 고정됩니다.

      ③ 결과 확인 · 저장

      1. 맨 위 노란 숫자가 총 개수입니다.
      2. 표시가 빠진 약은 터치하면 추가(흰 표시), 잘못 잡힌 표시는 터치하면 삭제됩니다.
      3. 약 이름을 적고(선택) ✅ 기록 저장을 누르면 기록 탭에 남습니다.

      표시 색의 뜻

      단독떨어져 있는 약 1알
      붙음맞닿은 약 — 한 알씩 나눠서 셈
      겹침다른 약에 가려진 약 — 추정값, 꼭 확인
      눕힘옆으로 누운 약
      세움세로로 선 약 — 추정값, 꼭 확인
      ✕ 회색반알·부서진 조각 — 세지 않음. 온알인데 ✕가 붙었다면 터치해서 직접 추가하세요
      직접 추가사용자가 터치로 추가한 약

      개수가 안 맞을 때

      • 적게 나오면 → 색 허용 범위를 오른쪽으로
      • 배경까지 잡히면 → 색 허용 범위를 왼쪽으로
      • 흰 약은 어두운 배경, 어두운 약은 밝은 배경에서 찍으세요.
      • 약과 색이 비슷한 물건(종이, 포장지)은 치워 주세요.
      • 약이 많이 겹치면 펼친 뒤 다시 찍는 것이 가장 정확합니다.

      📦 재고 관리 (병·낱알 단위)

      1. 재고 탭 → ＋ 약품 등록 → 약품명을 입력합니다.
      2. 포장 단위를 맞춥니다. 기본은 100정/1병이며, 아래 칸에 정 수와 단위(병·PTP·통)를 넣고 ＋ 포장 단위로 추가합니다.
      3. −/＋로 병 수·낱알을 입력합니다. 숫자를 누르면 직접 입력할 수 있습니다.
      4. 낱알이 많으면 📷 버튼 → 촬영 → 기준 약 터치 → 📦 낱알로 반영을 누르면 자동으로 채워집니다.
      5. ✅ 등록을 누르면 조사일과 함께 저장되고, 목록에 총 정 수와 내역이 표시됩니다.
      6. 약품을 다시 누르면 지난 수량이 채워진 상태로 열리고, 이전 조사 기록도 볼 수 있습니다.
      7. ⬇ 엑셀: 모든 조사 기록을 CSV 파일로 내려받아 엑셀에서 열거나 팀원에게 공유합니다.

      ▦ 바코드로 약품 찾기

      1. 재고 탭 → ▦ 바코드 → 약통·포장의 바코드(일반 바코드 또는 네모난 2D 바코드)를 노란 칸에 맞춥니다.
      2. 처음 보는 바코드면 등록 창이 열립니다. 약품명을 입력하고 ✅ 등록하면 바코드가 그 약품에 연결됩니다.
      3. 다음부터는 바코드만 비추면 약품명이 자동으로 찾아지고 재고 조사 창이 바로 열립니다.
      4. 2D 바코드에 들어 있는 유통기한·제조번호도 읽어서 함께 저장합니다. 유통기한이 90일 이내면 목록에 (임박)으로 표시됩니다.
      5. 계수 화면의 약 이름 칸 옆 ▦ 바코드로도 약 이름을 채울 수 있습니다.
      6. 바코드가 잘 안 읽히면 ⌨ 숫자 직접 입력으로 바코드 아래 숫자를 넣으세요.

      화면이 예전 그대로일 때

      • 맨 위 제목 옆 버전이 v3.1이 아니면 예전 화면이 저장된 것입니다.
      • 브라우저에서 새로고침하거나, 홈 화면 앱이면 앱을 완전히 닫았다가 다시 여세요. 업데이트 후 최대 10분 정도 걸릴 수 있습니다.

      기록 · 홈 화면 추가

      • 기록 탭: 저장한 결과를 최신순으로 보고, 약 이름으로 검색합니다. 항목을 누르면 사진 확대·이미지 저장·삭제가 됩니다.
      • 기록은 이 기기의 브라우저에만 저장됩니다(서버로 전송되지 않음). 브라우저 데이터를 지우면 함께 지워집니다.
      • 앱처럼 쓰기: 아이폰 Safari → 공유 → 홈 화면에 추가 / 안드로이드 Chrome → ⋮ 메뉴 → 홈 화면에 추가
      ※ 자동 계수는 보조 도구입니다. 조제·투약 전 최종 수량은 반드시 확인하세요.
