# 💊 필카운터 (Pill Counter)

카메라로 비추거나 사진을 찍으면 **같은 모양·크기·색의 약을 자동으로 세어 주는** 웹앱입니다.
설치 없이 핸드폰·노트북 브라우저에서 바로 쓰고, 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

**바로 쓰기 → https://gcode77.github.io/pillcounter/**

> 자동 계수는 보조 도구입니다. 조제·투약 전 최종 수량은 반드시 확인하세요.

---

## 주요 기능

| 기능 | 설명 |
|---|---|
| **자동 계수** | 기준 약을 고르지 않아도, 사진에서 같은 모습으로 반복되는 물체를 찾아 셉니다 |
| **실시간 계수** | 카메라를 비추는 동안 개수가 계속 표시됩니다(기본 켜짐, 켜기/끄기 가능) |
| **엄격한 기준 비교** | 기준 약과 면적·길이·폭·색이 모두 같은 것만 셉니다. 빈 화면·다른 물건은 세지 않습니다 |
| **붙은 약·바이알 분리** | 맞닿은 약, 빽빽한 바이알도 한 알씩 나눠서 셉니다 |
| **빛 반사 보정** | 약 위의 하얀 반사는 채우고, 쟁반 반사광은 약으로 세지 않습니다 |
| **반알 제외** | 반알·부서진 조각은 회색 ✕로 표시하고 개수에서 뺍니다 |
| **터치 초점 · 플래시** | 짧게 터치하면 초점, 오른쪽 위 버튼으로 플래시(지원 기기) |
| **직접 보정** | 결과에서 빠진 약은 터치해 추가, 잘못된 표시는 터치해 삭제 |
| **기록** | 계수 결과(사진·약 이름·날짜·개수)를 저장하고 검색 |
| **재고 관리** | 병·PTP 등 포장 단위 + 낱알로 약품별 재고 기록, 엑셀(CSV) 내보내기 |
| **바코드** | EAN-13·GS1 DataMatrix를 읽어 약품명 연결, 유통기한·제조번호 저장 |
| **업데이트 알림** | 새 버전이 올라오면 알림 → 누르면 내려받고 다시 시작 |

## 사용 순서

1. **촬영** — 약을 단색 배경 위에 펼치고 바로 위에서 비춥니다. 실시간 숫자가 멈추면 **촬영**.
2. **자동 계수** — 고화질로 다시 정밀하게 셉니다.
3. **결과** — 숫자를 확인하고, 필요하면 터치로 보정한 뒤 **기록 저장**(또는 재고에 **낱알로 반영**).

| 조작 | 동작 |
|---|---|
| 카메라 화면 짧게 터치 | 그 위치에 초점 |
| 카메라 화면 길게 누름(실시간) | 그 약과 같은 약만 세기 |
| 결과 화면 터치 | 빠진 약 추가 / 잘못된 표시 삭제 |
| 🎯 직접 선택 | 여러 약이 섞였을 때 셀 약 한 알을 직접 지정 |

### 정확하게 찍는 요령
- 약과 대비되는 **단색 배경**(흰 약 → 어두운 배경, 어두운 약 → 밝은 배경)
- 약을 **펼쳐서**, 핸드폰을 **바로 위에서 수평**으로
- 약과 색이 비슷한 종이·포장지는 치우기, 강한 반사광 피하기

### 홈 화면에 추가
- 아이폰 Safari: 공유 → **홈 화면에 추가**
- 안드로이드 Chrome: ⋮ 메뉴 → **홈 화면에 추가**

## 표시 색

| 색 | 뜻 |
|---|---|
| 🟢 초록 | 떨어져 있는 약 1알 |
| 🟣 분홍 | 맞닿은 약 — 한 알씩 나눠서 셈 |
| 🔴 빨강 | 다른 약에 가려진 약 — 추정값, 확인 필요 |
| ⚪ 흰색 | 사용자가 직접 추가 |
| ✕ 회색 | 반알·조각 — 세지 않음 |

## 파일 구조

```
index.html            화면·흐름·기록·재고·바코드·업데이트 (한 파일)
engine.js             계수 엔진 — Web Worker로 백그라운드 실행
version.json          최신 버전 정보(업데이트 알림용)
manifest.webmanifest  홈 화면 앱 설정
icons/                앱 아이콘
vendor/zxing.min.js   바코드 인식 라이브러리 (ZXing, Apache-2.0)
```

## 계수 방식 (engine.js)

1. **자동 기준 찾기** — 작은 사본에서 주요 색마다 물체를 나누고, *반복 횟수 × 크기 × 매끈함*이 가장 큰 물체를 기준 약으로 고릅니다.
2. **색 영역** — 기준색과의 색 거리(Lab) 분포에서 골짜기를 찾아 경계값을 자동으로 정합니다.
3. **반사 보정** — 거의 흰색인 작은 반사만 약에 채웁니다.
4. **분리** — 거리 변환으로 약의 중심부를 찾고, 1알보다 큰 중심부는 더 깊이 봐서 봉우리별로 나눕니다.
5. **대표값** — 1알의 면적·두께·색을 사진 전체에서 *가장 흔한 값*으로 정해, 어느 약을 기준으로 해도 결과가 같습니다.
6. **판정** — 기준과 면적·길이·폭이 맞는 것만 셉니다. 자동 모드에서는 같은 모습이 3개 이상이고 주변과 대비가 뚜렷해야 결과를 인정합니다.

무거운 계산은 Web Worker에서 돌아 화면이 멈추지 않으며, 사진 15초·실시간 4초를 넘기면 자동으로 중단합니다.

## 데이터 저장

기록과 재고는 **그 기기 브라우저의 localStorage에만** 저장되며 서버로 전송되지 않습니다.
브라우저 데이터를 지우면 함께 지워지고, 다른 기기와는 공유되지 않습니다(재고는 CSV로 내보내 공유).

## 개발

빌드 과정이 없는 정적 파일입니다. 카메라는 HTTPS 또는 `localhost`에서만 동작합니다.

```bash
python -m http.server 8765
```

브라우저에서 `http://localhost:8765` 를 엽니다.

### 배포(업데이트 내보내기)

GitHub Pages(`main` 브랜치 루트)로 배포됩니다. 새 버전을 낼 때는 **세 곳의 버전을 함께** 올립니다.

1. `index.html` — `APP_VERSION`, 머리글의 `vX.Y`, `engine.js?v=X.Y`
2. `version.json` — `version`, `notes`(알림에 보일 한 줄)
3. `CHANGELOG.md` — 변경 내용

`main`에 푸시하면 1~2분 뒤 반영되고, 사용 중인 앱에 업데이트 알림이 뜹니다.
